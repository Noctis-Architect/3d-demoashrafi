# بررسی کیفیت

هیچ مرحله‌ای رو بدون دیدن نتیجه تموم‌شده اعلام نکن. «کد درست اجرا شد» یعنی هیچی؛ باید عکس نتیجه رو کنار عکس محصول ببینی.

## سرور توسعه
`.claude/launch.json` یه پیکربندی `sofa-dev` داره که `scripts/devserver.py` رو روی پورت ۸۷۹۴ اجرا می‌کنه: بدون کش، و با `PUT /__shot/<name>.png` که عکس رو تو `/tmp/scan-work/shots/` ذخیره می‌کنه.
- `preview_start {name:"sofa-dev"}` ← `http://localhost:8794/<id>.html`
- ابزارهای تست موتور فقط روی localhost فعال‌ان.

## عکس از زاویه‌های ثابت
تو `javascript_tool`:
صفحه رو با `?shot` باز کن (چرخش خودکار خاموش). اول صبر کن تا بافت‌ها برسن، وگرنه عکس با رنگ سادهٔ موقت گرفته می‌شه:
```js
for(let i=0;i<60&&!(window.__view&&!document.getElementById('busy').classList.contains('on'));i++) await new Promise(r=>setTimeout(r,500));
const png = __view([1.6,0.75,2.4],[0,0.38,0],1400,900,30);   // [مکان دوربین]، [هدف]، عرض، ارتفاع، fov
await fetch('/__shot/<id>-front34.png',{method:'PUT',body:await (await fetch(png)).blob()});
```
- حداقل چهار زاویه: جلو، سه‌رخ، بغل، و نزدیک از کنده‌کاری یا درز چوب و پارچه. همون زاویه‌ای که عکس محصول گرفته شده رو هم بساز.
- `__openAll(1)` همهٔ کشوها رو باز می‌کنه؛ `__toggleAll()` باز و بسته.
- بعد عکس‌ها رو با Read ببین و یکی‌یکی با عکس‌های `refs/<id>/` مقایسه کن.
- برای گزینه‌ها، URL رو با پارامتر عوض کن (`?c=5b1a1c&ft=velvet`) و دوباره عکس بگیر. **هر** رنگ و جنس رو حداقل یه بار ببین؛ مشکل جدا نشدن چوب از پارچه فقط وقتی رنگ عوض می‌شه دیده می‌شه.

## تست سوراخ و پارگی
```bash
python3 .claude/skills/new-product/scripts/s2viz.py /tmp/scan-work/s2/<id>_np /tmp/scan-work/look/<id>.glb
blender -b --python .claude/skills/new-product/scripts/holecheck.py -- /tmp/scan-work/look/<id>.glb /tmp/scan-work/look/<id>_holes
```
پس‌زمینه سرخابیه و پشت سطح‌ها حذف می‌شه، درست مثل سایت. هر نقطهٔ سرخابی روی مبل یعنی سوراخ یا درز باز. شش زاویه رو ببین، از جمله زیر و پشت.

## چک‌لیست تحویل

**فرم**
- [ ] از جلو، سه‌رخ و بغل، شکل و تناسب با GLB یکیه (عکس‌ها رو کنار رندر `render.py` خود GLB بذار).
- [ ] کنده‌کاری‌ها کامل‌ان: نرم یا محو نشدن، چیزی جاشون ساخته نشده.
- [ ] هر جا اسکن با عکس فرق داشت (`notes.md`)، مثل عکس شده.
- [ ] تقارن چپ و راست؛ اصلاح موضعی بقیه رو جابه‌جا نکرده.
- [ ] پشت مبلمان دیوارکوب صافه.
- [ ] ابعاد برچسب صفحه با ابعاد واقعی یکیه.

**سطح**
- [ ] هیچ سوراخ یا درز سرخابی‌ای نیست، به‌خصوص بین چوب و پارچه.
- [ ] پارچه چروک اسکن نداره، ولی خط‌های طراحی‌شده (کاپیتونی، خط دسته و تاج) سر جاشون‌ان.
- [ ] با عوض کردن رنگ چوب، هیچ لکه‌ای از چوب روی پارچه یا برعکس نمی‌مونه.
- [ ] نوار یا خط هم‌تراز روی پارچهٔ صاف نیست (اگه هست، اون slot رو با `RN` encode کن).
- [ ] براقی مثل عکسه؛ هیچ چیز بی‌دلیل براق نیست.

**قطعه‌های کدی**
- [ ] کوسن‌ها تو مبل فرو نمی‌رن، از دسته رد نمی‌شن، از هم رد نمی‌شن، و موقع کشیدن به جلو روی نشیمن می‌خوابن.
- [ ] شکل کوسن مثل عکسه (مربعی یا نرم، ضخامت، گوشه‌ها).
- [ ] کشو باز و بسته می‌شه، داخلش همرنگ بدنه‌ست، و از هیچ زاویه‌ای جعبه یا ریل بیرون نمی‌زنه.

**عملکرد**
- [ ] `assets/models/<id>.js` حدود ۱ تا ۵ مگه.
- [ ] روی موبایل (`resize_window` با `preset:"mobile"`) بار می‌شه و چرخوندن روونه. پیام خطا (`read_console_messages`) نیست.
- [ ] بار اول صفحه رنگ ساده میاد و بعد بافت؛ نیاز به رفرش نیست.
- [ ] دکمهٔ AR: بار اول آماده می‌شه («✓ آماده است — بزنید»)؛ GLB خروجی اندازهٔ واقعی داره.
- [ ] لینک طرح (کپی لینک) همون طرح رو دوباره باز می‌کنه.
