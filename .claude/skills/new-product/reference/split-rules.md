# کدوم بخش از اسکن، کدوم با کد

اول همیشه فرض کن **همه‌چیز از اسکن**ه. فقط وقتی یکی از دلیل‌های پایین صدق کرد، اون بخش با کد ساخته می‌شه.

## قانون‌ها

| بخش | منبع | چرا / چطور |
|---|---|---|
| کنده‌کاری، منبت، تاج، پایهٔ کابریول، ستون جلوی دسته، کلاف | **اسکن، همیشه** | با کد هیچ‌وقت شبیه نمی‌شه. اگه اسکن کلاف رو خراب کرده، کلاف رو دوباره از خود GLB بردار (`frame_from_scan.py`)، نه با کد. |
| بدنهٔ رویه‌دار با فرم خاص (کاپیتونی، دستهٔ لوله‌ای، پلان قوس‌دار) | **اسکن** | چروک اسکن رو صاف کن (`poisson_unpillow.py --chan --flat --iso --crease`)، ولی خط‌های طراحی‌شده (کانال‌های کاپیتونی، خط دسته و تاج) **باید بمونن**. |
| تشک نشیمن ثابت | **اسکن** | slot جدا (`seat` در نیمکت، `cushion` در چستر). گوشه‌ها و جدا شدن از پشتی رو مثل عکس کن (`--box`، `--tuck`). |
| کوسن تزئینی | **کد، همیشه** | کوسن‌های اسکن رو بردار و زیرشون رو بازسازی کن (`poisson_unpillow.py`). کوسن کدی: `addPillows` (ساده، با `solids` روی سطح واقعی اسکن) یا `addSoftPillows` (نرم با برخورد، برای بدنهٔ کدی). شکل از عکس: `shape:'square'` یا `'soft'`. |
| کشوی بازشو، در | **کد** | ولی هر منحنی (لبهٔ کشو، دامنه، رویه) از GLB اندازه‌گیری می‌شه و تو جدول نمونه ذخیره می‌شه (مثل `console.js`، هر ۱ تا ۵ سانت). پیش‌فرض کنسول «تزئینی»ه: فقط در کشو، بدون جعبه. |
| دستگیره، یراق | **کد** | `hardware.js` (`addHandle`)، با رنگ جدا (`trim`). |
| قطعهٔ کنده‌کاری که روی بخش کدی می‌شینه (گل منبت روی دامنهٔ کنسول) | **اسکن، فایل جدا** | با همون جعبهٔ کوانتش مدل اصلی (`BOX=…` در encode) تو `models/<id>-<part>.js`؛ از مدل اصلی هم با یه تابع مثل `trimCarve` حذفش کن تا دوبار نیاد. |
| محصول ماژولار (تعداد نشیمن، سمت شزلون) و بی‌کنده‌کاری | **کد، با احتیاط** | مثل `sectional.js`: هر قطعه یه `upBox` با اندازه‌های برش‌خورده از GLB. ولی این کار یه بار «بشدت کارتونی» شد؛ چین ملایم، شکم، گودی نشستن، قیطان و سایهٔ تماس (`bakeAO`) لازمه. اگه ماژولار بودن لازم نیست، از اسکن بساز. **قبلش از کاربر بپرس.** |
| قطعهٔ تکراری در مدل کدی (پایه‌ها) | **اسکن، یه نمونه** | یه پایه از اسکن (`models/sectional-leg.js`) و `setLeg` برای همهٔ جاها. |
| سطح صاف و ساده که اسکن موج‌دار یا خراب کرده (پشت کنسول، نوار پشت زیر نشیمن) | **اصلاح موضعی روی خود اسکن** | فقط رأس‌های همون ناحیه رو صاف کن (مثل `flatten_back_apron.mjs`). پشت مبلمانی که به دیوار می‌چسبه کاملاً صافه. |
| نقص قرینه‌سازی (نوک تیز وسط تاج) | **اصلاح موضعی** | `flatten_crest.mjs`. فقط همون نقطه، تقارن دست نخوره. |
| بیرون‌زدگی بیش از عکس | **ضریب روی اندازهٔ اسکن** | مثل `BULGE=0.7` در `console.js`، فقط روی همون بخش، دو سر و وسط ثابت. |

## اسم slot ها (یکسان نگه دار)

| slot | یعنی | محصول |
|---|---|---|
| `wood` | کل چوب کنده‌کاری | نیمکت |
| `seat` | تشک | نیمکت |
| `fabric` | رویهٔ بدنه | چستر، ساحل |
| `cushion` | تشک یا کوسن پشتی ثابت | چستر، ساحل |
| `frame` | کلاف و پایه‌ها | چستر |
| `legs` | پایه | ساحل |
| `pillows` | کوسن‌های تزئینی کدی | چستر، ساحل |
| `welt` | قیطان | ساحل |
| `carve` | پایه‌ها و کنده‌کاری | کنسول |
| `front`, `top` | بدنهٔ کدی | کنسول |
| `trim`, `inner`, `cavity` | دستگیره، داخل کشو، حفرهٔ پشت کشو | کنسول |

هر slot یه رنگ مستقل تو پنل می‌گیره، مگر اینکه با `also` به یه part دیگه وصل بشه (مثلاً `fabric` با `also:['cushion']`).

## چهار محصول فعلی، به‌عنوان نمونه

| محصول | از اسکن | با کد |
|---|---|---|
| نیمکت `chaise` | `wood` (۲۷۳ هزار رأس)، `seat` | هیچ (به‌جز دو اصلاح موضعی روی خود اسکن) |
| چستر `chester` | `fabric`، `cushion`، `frame` (کلاف دقیقاً از GLB، نیمهٔ چپ قرینه) | کوسن‌ها (`addPillows` با `solids`، شکل `square`) |
| ساحل `sectional` | فقط یک پایه | بدنه، تشک، پشتی، دسته، کوسن‌ها (`sectional.js` + `addSoftPillows`) |
| کنسول `console` | `carve` (پایه‌ها و ستون‌ها)، گل منبت (فایل جدا) | رویه، دامنه، کشوها، دستگیره (`console.js` + `hardware.js`) |
