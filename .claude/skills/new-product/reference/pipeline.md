# کارخانهٔ تبدیل: GLB ← `assets/models/<id>.js`

همهٔ اسکریپت‌ها تو `tools/scan/` ـن و از **داخل همون پوشه** اجرا می‌شن. پوشهٔ کار `/tmp/scan-work` با زیرپوشه‌های `raw`، `s1`، `s2`، `look` ـه. `/tmp` با ری‌استارت پاک می‌شه؛ هر چیزی که برای دوباره ساختن لازمه، دستورش باید تو `tools/scan/README.md` نوشته بشه.

## آماده‌سازی محیط (یک بار)

- `gltf-transform` و ماژول‌های `meshoptimizer` و `sharp` در `~/.npm-global` نصب‌ان. اسکریپت‌های `.mjs` از همون مسیر import می‌کنن.
- Blender در `/usr/bin/blender` هست (برای رندر و `solidify.py`).
- پایتون سیستم numpy، scipy و PIL داره، ولی **pymeshlab نداره**. برای `poisson_unpillow.py` و `poisson_wood.py`:
  `bash .claude/skills/new-product/scripts/setup-venv.sh` ← محیط `~/.venvs/scan`، بعد با `~/.venvs/scan/bin/python` اجرا کن.
- `mkdir -p /tmp/scan-work/{raw,s1,s2,look}`

## مرحله‌ها

### ۱. باز کردن فشرده‌سازی
```bash
gltf-transform dequantize ../../3d/<file>.glb /tmp/scan-work/raw/<id>.glb
```
فایل‌های Tripo فشرده (quantized/meshopt) ـن. بعد از این مرحله `render.py` رو روی `raw/<id>.glb` اجرا کن و جهت جلو و رنگ‌ها رو ببین.

### ۲. ساده‌سازی دقیق (`stage1.mjs`)
```bash
node --max-old-space-size=14000 stage1.mjs /tmp/scan-work/raw/<id>.glb /tmp/scan-work/s1/<id> 0.0002 1
```
- آرگومان سوم: خطای مجاز نسبی (۰٫۰۰۰۲ شعاع ≈ ۰٫۲ میلی‌متر روی یه مبل ۲ متری). **بیشترش نکن**؛ کنده‌کاری از بین می‌ره. برای سبک‌تر کردن بعداً `lite.mjs` رو فقط روی بخش‌های صاف بزن.
- آرگومان چهارم: وزن نرمال در ساده‌سازی. با `1`، لبه‌های کنده‌کاری نگه داشته می‌شن.
- `RECALC=1` نرمال‌ها رو از نو حساب می‌کنه (معمولاً لازم نیست؛ نرمال اصلی اسکن بهتره).
- خروجی: `s1/<id>.{json,bin}` (مکان، نرمال، UV، اندیس، رنگ هر رأس از بافت اسکن)، `s1/<id>_normal.png` (نرمال‌مپ اصلی)، و `s1/<id>_test.glb` برای مقایسه با اصل.

### ۳. برچسب بخش‌ها (`seg.py`، بعد `seg2.py`)
- `seg.py` برای هر مدل یه شاخهٔ `elif name=='<id>':` داره که با رنگ اسکن (`v` روشنی، `s` اشباع، `c` رنگ) و مکان (**در مختصات خود فایل، قبل از چرخش stage2**) برچسب می‌زنه: ۰ پارچه، ۱ چوب، ۲ کوسن… و `k` (تعداد کلاس‌ها) رو همون‌جا تعیین می‌کنه. بعد چند دور فیلتر اکثریت روی همسایه‌ها.
  ```bash
  python3 seg.py <id> 3        # آرگومان دوم: تعداد دور هموارسازی (پیش‌فرض ۳)
  ```
  خروجی `s1/<id>_lab.npy` و `s1/<id>_lab.glb` (رنگی). ببین: `blender -b --python render.py -- /tmp/scan-work/s1/<id>_lab.glb /tmp/scan-work/look/<id>_lab VERTEX`
- برای مبل‌هایی که چوب و پارچه کنار هم دارن، `seg2.py` لازمه (برچسب به ازای **هر مثلث**، مرز روی شیار واقعی): یه ورودی تو `CFG` اضافه کن: `length` (طول واقعی)، `rail` (ارتفاع لبهٔ بالای ریل چوبی، متر)، `post` (محدودهٔ `|x|` و `z` ستون‌های جلوی دسته)، `beta` (نرمی مرز)، `mn` (کوچک‌ترین جزیره‌ای که می‌مونه).
  ```bash
  python3 seg2.py <id>
  ```
  خروجی `s1/<id>_flab.npy`؛ stage2 خودکار ازش استفاده می‌کنه.
- **اشتباه رایج:** رنگ پارچه روی ریل چوبی نشت کرده (بافت اسکن). برای همین seg2 زیر خط `rail` رو چوب حساب می‌کنه. اگه بعد از تغییر رنگ چوب لکهٔ پارچه روی کلاف دیدی، مشکل از این مرحله‌ست.

### ۴. جهت، اندازهٔ واقعی، سایه (`stage2.py`)
یه ورودی به `CFG` اضافه کن:
```python
'<id>': dict(front='+x', length=2.24, slots=['fabric', 'frame', 'pillows']),
```
- `front`: کدوم جهت فایل جلوی محصوله (`+x`، `-x` یا هیچ). از رندر مرحلهٔ ۱ تشخیص بده.
- `length`: طول بلندترین ضلع به متر (از سایت فروشگاه یا کاربر). همه‌چیز با همین مقیاس می‌شه.
- `slots`: اسم برچسب‌ها به ترتیب شمارهٔ کلاس‌ها.
```bash
python3 stage2.py <id>
```
خروجی `s2/<id>.{json,bin}`: کف روی `y=0`، جلو `+z`، وسط روی `x=0`؛ رنگ پیش‌فرض هر بخش = میانهٔ رنگ اسکن؛ سایه = روشنی نسبی هر رأس (برای گودی کنده‌کاری‌ها). ابعاد چاپ‌شده رو با ابعاد واقعی چک کن.

### ۵. (فقط وقتی کوسن کدی داره) برداشتن کوسن اسکن و تمیز کردن بدنه
```bash
~/.venvs/scan/bin/python poisson_unpillow.py <id> --depth 10 --smooth 30 --chan 0.05 --flat 0.035 --iso 0.03 --mirror left --rail 0.25 --post 0.957,0.42 --erode 12 --wood-holes 400 --push 0.015
```
خروجی `s2/<id>_np.{json,bin}` (بدون slot `pillows`). پارامترهای مهم:

| پارامتر | کار |
|---|---|
| `--depth`، `--tris` | دقت بازسازی Poisson و سقف مثلث‌ها |
| `--smooth`، `--iron` | صاف کردن کلی (Taubin) و صاف کردن قوی‌تر در ناحیه‌ای با شرط (مثل `"(x>-0.2)&&(x<0.2)&&(y>0.5)"`) |
| `--chan` / `--flat` / `--iso` | صاف کردن در جهت کانال‌های کاپیتونی، روی سطوح تخت، و همسان |
| `--crease` | نگه داشتن خط‌های تیز طراحی (خط دسته و تاج؛ کاربر گفت «اون خط رو برگردون») |
| `--mirror left/right` | نیمهٔ تمیزتر رو قرینه کن |
| `--rail`، `--post`، `--post-in` | خط بالای ریل چوبی، و ستون‌های جلوی دسته که دست نمی‌خورن |
| `--hem`، `--hem-push`، `--push` | لبهٔ پارچه کنار چوب کمی عقب‌تر، تا همیشه چوب جلو باشه و پشت درز پارچه باشه، نه پس‌زمینه |
| `--box`، `--box-k` | گوشه‌های تیزتر برای تشک جعبه‌ای |
| `--tuck`، `--tuck-band` | فرورفتگی لبهٔ پشت تشک، تا جدا بودنش از پشتی دیده بشه |
| `--wood-from <prefix>` | برچسب چوب از یه نسخهٔ دیگه؛ نقطه‌های پارچه روی اون چوب حذف می‌شن |
| `--erode`، `--wood-holes`، `--fill` | تمیز کردن مرز برچسب و پر کردن سوراخ |
| `--shade-blur` | محو کردن سایهٔ پختهٔ اسکن روی پارچه (چروک‌های تیره) |

بعدش کلاف رو **دقیقاً از خود فایل** برگردون (فقط نیمهٔ چپ قرینه، برش صاف روی خط ریل):
```bash
python3 frame_from_scan.py /tmp/scan-work/s2/<id>_np /tmp/scan-work/s2/<id>_newlab left 0.249 0.94,0.40
```
آرگومان‌ها: پیشوند بدنه، پیشوند کلاف اسکن (خروجی stage2)، سمت قرینه، ارتفاع ریل، `|x|,z` ستون‌ها.

اختیاری: `solidify.py` (در Blender) یا `poisson_wood.py` برای چوبی که فقط از جلو اسکن شده و از پشت سوراخه.

### ۶. (اختیاری) سبک‌سازی دوباره (`lite.mjs`)
```bash
node lite.mjs ../../assets/models/<id>.js ../../assets/models/<id>.js frame=0.65 fabric=0.75
```
فقط روی بخش‌هایی که صاف‌ان. هیچ‌وقت روی چوب کنده‌کاری زیر ۰٫۶۵ نرو.

### ۷. ساخت فایل کد (`encode.mjs`)
```bash
RN=fabric,cushion node encode.mjs /tmp/scan-work/s2/<id>_np ../../assets/models/<id>.js <id> tex/scan/<id>_normal.webp
```
- `RN=slot1,slot2`: نرمال این بخش‌ها تو مرورگر از نو و با دقت کامل حساب بشه. برای پارچه‌های صاف لازمه، وگرنه نرمال ۸ بیتی نوارهای هم‌تراز می‌سازه.
- `BOX="cx,cy,cz,half"`: برای قطعه‌ای که روی مدل اصلی می‌شینه (گل منبت)، تا با همون جعبهٔ کوانتش ساخته بشه.
- اندازهٔ چاپ‌شده رو ببین؛ هدف ۱ تا ۵ مگه.

### ۸. نرمال‌مپ
```bash
python3 -c "from PIL import Image; im=Image.open('/tmp/scan-work/s1/<id>_normal.png'); im.thumbnail((2048,2048)); im.save('../../tex/scan/<id>_normal.webp',quality=92)"
```
نرمال‌مپ فقط روی چوب استفاده می‌شه (`SURF.wood` با `M.normalMap`).

## اصلاح موضعی روی فایل مدل ساخته‌شده

وقتی فقط یه ناحیهٔ کوچیک با عکس فرق داره، کل مسیر رو دوباره اجرا نکن. یه اسکریپت کوچیک مثل `flatten_crest.mjs` یا `flatten_back_apron.mjs` بنویس:
1. `assets/models/<id>.js` رو import کن و slot مورد نظر رو با `MeshoptDecoder` باز کن.
2. فقط رأس‌هایی رو که تو یه ناحیهٔ دقیق (با `|x|` برای حفظ تقارن) هستن جابه‌جا کن، با محو شدن نرم تا لبهٔ ناحیه.
3. برای سطح صاف‌شده: نرمال تخت، و UV روی یه نقطهٔ خنثی از نرمال‌مپ، تا سایهٔ کنده‌کاری قبلی دیده نشه.
4. دوباره encode کن و همون فایل رو بنویس.
5. دستور دقیقش رو تو `tools/scan/README.md` زیر اسم محصول بنویس.
